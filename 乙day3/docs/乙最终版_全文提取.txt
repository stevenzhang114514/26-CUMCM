### 第 6 页

问题4中，半径随时间缩⼩，R(t) 从 2.000 cm 降到 1.198 cm，计算域是 [0, R(t)]，
随时间变化。 
3.2 为什么要⽤坐标变换 
如果直接⽤物理坐标 r 求解，计算域 [0, R(t)] 随时间缩⼩，⽹格必须不断移动，
处理起来很⿇烦。 
引⼊归⼀化坐标： 
xi = r / R(t)，xi 属于 [0, 1] 
这样计算域固定在 [0, 1]，⽹格不动，边界固定在 xi = 0 和 xi = 1。 
3.3 均匀径向仿射收缩假设 
附件2只给出整体半径 R(t)，没有给出内部各点的位移数据。 
因此假设：内部各点按⽐例均匀收缩，即材料径向速度 
v_r = (R'(t) / R(t)) * r 
其中 R'(t) = dR/dt。 
这是问题4主模型的核⼼假设。必须声明：这是⼀个假设，不是由数据验证的
结论。 
3.4 坐标变换后的控制⽅程 
定义归⼀化变量： 
C_tilde(xi, t) = C(xiR(t), t)T_tilde(xi, t) = T(xiR(t), t) 
在均匀仿射收缩假设下，⽔分和温度⽅程变为： 
⽔分⽅程： 
d(C_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
温度⽅程： 

======================================================================
### 第 7 页
======================================================================
rho * cp * d(T_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * k * d(T_tilde)/dxi ) 
注意：因为材料随⽹格均匀收缩，对流项被消掉，⽅程形式⽐固定坐标下更简
洁。R(t) 只以 R(t)^2 的形式出现在分母上。 
3.5 边界条件 
中⼼ xi = 0（对称条件）： 
d(C_tilde)/dxi = 0d(T_tilde)/dxi = 0 
表⾯ xi = 1（对流边界）： 
-(D / R) * d(C_tilde)/dxi = hm * (C_tilde_s - C_inf)-(k / R) * d(T_tilde)/dxi = h * 
(T_tilde_s - T_inf) 
注意：表⾯边界带 1/R 因⼦，这是坐标变换的结果。 
3.6 物性公式（附录4） 
rho = 760 + 90 * Ccp = 1850 + 2150 * C / (C + 1)k = 0.12 + 0.20 * C / (C + 1)D = 
4.2e-4 * exp(-0.30 / C) * exp(-3850 / T_K) 
其中 T_K = T + 273.15（摄⽒转开尔⽂）。

5.3 调试过程 
第⼀步：检查求解器 
⽤MATLAB内置求解器与thomas函数对⽐： 
max|thomas - builtin| = 1.77e-15 
结果为机器精度，说明thomas函数本⾝正确，问题在⽅程的组装。 
第⼆步：检查矩阵组装⽅向 
初版代码： 
dl = [-G; 0]du = [0; G] 
修正为： 
dl = [0; -G] 
结果：T(1) 不再直接掉到 0，但在 -0.85~1.62 之间抖动，仍不合理。 
第三步：检查矩阵组装符号 
进⼀步分析发现，三对⾓矩阵的对⾓项应该满⾜： 
dd(i) = cap(i) + GT(i) + GT(i-1) 
上对⾓ du(i) = -GT(i)（应为负号）。 
初版代码⾥ du 写成了正号，导致⽅程符号错误。 
修正为： 
dl = [0; -G]du = [-G; 0]

结果：T(1) 稳定在 28 ℃ 并缓慢上升，温度⽅程修对。 
第四步：检查表⾯边界条件 
温度⽅程修对后，发现表⾯含⽔率 C(end) 在100秒内从 2.55 掉到 0.29，下降过
快。 
诊断输出显⽰： 
hm / (R*dxi) / G(end) = 16 
即表⾯传质项是扩散项的16倍，表⾯被瞬间拉向环境值。 
第五步：重新推导表⾯边界条件的离散形式 
归⼀化坐标 ξ = r/R(t) 下，表⾯控制体⽅程： 
w_N (C_N^{n+1} - C_N^n) / dt= (1/R^2) * [ D * dC/dxi |{ξ=1} * ξ - xi_w * D_f * 
(C_N - C{N-1}) / dxi ] 
表⾯边界条件： 
(D / R) * dC/dxi |_{xi=1} = hm * (C_N - C_inf) 
即： 
D * dC/dxi |_{xi=1} = -R * hm * (C_N - C_inf) 
代⼊控制体⽅程，展开后： 
对⾓项 = w_N/dt + G_w + hm/R右端项 = w_N/dt * C_N^old + hm/R * C_inf 
其中 G_w = xi_w * D_f / (R^2 * dxi)。 
关键：边界项是 hm/R，不是 hm/(R*dxi)，也不是 hm。 
第六步：修正表⾯边界项 
将表⾯边界项从 hm/(Rdxi) 改为 hm/R，温度边界同理从 h/(Rdxi) 改为 h/R。

9.4.1 检验⽬的 
问题4采⽤材料坐标（xi = r/R(t)）求解。理论上，同⼀个物理过程也可以⽤固

9.4.2 两种写法的⽅程 
写法A（材料坐标，问题4代码采⽤）： 
d(C_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * D * d(C_tilde)/dxi )xi = r/R(t)，
C_tilde(xi, t) = C(xi*R(t), t) 
写法B（固定坐标 + 坐标项）： 
d(C)/dt |_r = 1/r * d/dr ( r * D * d(C)/dr ) + (R'(t)/R(t)) * r * d(C)/drR'(t) = dR/dt 
9.4.3 等价性推导 
由链式法则： 
d(C)/dt |_r = d(C_tilde)/dt |_xi - (R'(t)/R(t)) * xi * d(C_tilde)/dxi
