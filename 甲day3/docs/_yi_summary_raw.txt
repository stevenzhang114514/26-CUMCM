三、收缩坐标推导 
本节公式采⽤纯⽂本写法（xi 代表 ξ，C_tilde 代表 C̃），以避免复制粘贴时出现乱码。符号
对照表如下： 
| 纯⽂本写法 | 对应数学符号 | 含义 | 
| :--- | :--- | :--- | 
| xi | ξ | 归⼀化坐标，xi = r/R(t) | 
| C_tilde | C̃ | 归⼀化后的⽔分浓度 | 
| T_tilde | T̃ | 归⼀化后的温度 | 
| d(...)/dt | ∂/∂t | 对时间求偏导 | 
| d(...)/dxi | ∂/∂ξ | 对 xi 求偏导 | 
| R'(t) | Ṙ | 半径变化率 dR/dt | 
| rho | ρ | 密度 | 
| cp | c_p | ⽐热容 | 
| k | k | 热传导系数 | 
| D | D | ⽔分扩散系数 | 
| hm | h_m | 对流传质系数 | 
| h | h | 对流换热系数 | 
| C_inf | C∞ | 环境⽔分浓度 | 
| T_inf | T∞ | 环境温度 | 
3.1 问题4 与问题1-3 的区别 
问题1-3 中，药材半径固定 R0 = 2 cm，计算域是 [0, R0]。 
问题4 中，半径随时间缩⼩，R(t) 从 2.000 cm 降到 1.198 cm，计算域是 [0, R(t)]，
随时间变化。 
3.2 为什么要⽤坐标变换 
如果直接⽤物理坐标 r 求解，计算域 [0, R(t)] 随时间缩⼩，⽹格必须不断移动，
处理起来很⿇烦。 
引⼊归⼀化坐标： 
xi = r / R(t),    xi 属于 [0, 1] 
这样计算域固定在 [0, 1]，⽹格不动，边界固定在 xi=0 和 xi=1。 
3.3 均匀径向仿射收缩假设 
附件2 只给出整体半径 R(t)，没有给出内部各点的位移数据。 
因此假设：内部各点按⽐例均匀收缩，即材料径向速度 
v_r = (R'(t) / R(t)) * r 
其中 R'(t) = dR/dt。 
这是问题4 主模型的核⼼假设。必须声明：这是⼀个假设，不是由数据验证的
结论。 
3.4 坐标变换后的控制⽅程 
定义归⼀化变量： 
C_tilde(xi, t) = C(xi * R(t), t) 
T_tilde(xi, t) = T(xi * R(t), t) 
在均匀仿射收缩假设下，⽔分和温度⽅程变为： 
⽔分⽅程： 
d(C_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
温度⽅程： 
rho * cp * d(T_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * k * d(T_tilde)/dxi ) 
注意：因为材料随⽹格均匀收缩，对流项被消掉，⽅程形式⽐固定坐标下更简
洁。R(t) 只以 R(t)^2 的形式出现在分母上。 
3.5 边界条件 
中⼼ xi = 0（对称条件）： 
d(C_tilde)/dxi = 0 
d(T_tilde)/dxi = 0 
表⾯ xi = 1（对流边界）： 
-(D / R) * d(C_tilde)/dxi = hm * (C_tilde_s - C_inf) 
-(k / R) * d(T_tilde)/dxi = h * (T_tilde_s - T_inf) 
注意：表⾯边界带 1/R 因⼦，这是坐标变换的结果。 
3.6 物性公式（附录4） 
rho = 760 + 90 * C 
cp = 1850 + 2150 * C / (C + 1) 
k = 0.12 + 0.20 * C / (C + 1) 
D = 4.2e-4 * exp(-0.30 / C) * exp(-3850 / T_K) 
其中 T_K = T + 273.15（摄⽒转开尔⽂）。 
3.7 初始条件 
T(xi, 0) = 28 摄⽒度 
C(xi, 0) = 2.55 kg/kg 
3.8 半径函数 
R(t) 由附件2 的 PCHIP 插值给出，存放在 R_fit.mat ⽂件中。 
R(t) 从 2.000 cm 单调递减到 1.198 cm，覆盖 0 到 259200 s（72 ⼩时）。

五、问题4 代码调试记录 
5.1 调试⽬标 
问题4 代码需要模拟圆柱形药材在烘⼲过程中，半径随时间缩⼩的情况下， 
温度和⽔分浓度的变化，并找出全场最⼤含⽔率降⾄ 0.15 以下的时刻 t_dry。 
5.2 初版问题 
初版代码跑出的结果物理上不合理： 
  - 中⼼温度 T(1) 在 60 秒内从 28℃ 掉到 0℃，⽽环境温度是 28~50℃ 
  - 表⾯含⽔率 C(end) 在 100 秒内从 2.55 掉到 0.29，下降过快 
  - ⼲燥时间 t_dry = 3.59 h，远短于题⽬背景的 2-3 天 
5.3 调试过程 
第⼀步：检查求解器 
⽤ MATLAB 内置求解器与 thomas 函数对⽐： 
  max|thomas - builtin| = 1.77e-15 
结果为机器精度，说明 thomas 函数本⾝正确，问题在⽅程的组装。 
第⼆步：检查矩阵组装⽅向 
初版代码： 
  dl = [-G; 0] 
  du = [0; G] 
修正为： 
  dl = [0; -G] 
  du = [G; 0] 
结果：T(1) 不再直接掉到 0，但在 -0.85 ~ 1.62 之间抖动，仍不合理。 
第三步：检查矩阵组装符号 
进⼀步分析发现，三对⾓矩阵的对⾓项应该满⾜： 
  dd(i) = cap(i) + GT(i) + GT(i-1) 
  上对⾓ du(i) = -GT(i)（应为负号） 
初版代码⾥ du 写成了正号，导致⽅程符号错误。 
修正为： 
  dl = [0; -G] 
  du = [-G; 0] 
结果：T(1) 稳定在 28℃ 并缓慢上升，温度⽅程修对。 
第四步：检查表⾯边界条件 
温度⽅程修对后，发现表⾯含⽔率 C(end) 在 100 秒内从 2.55 掉到 0.29， 
下降过快。 
诊断输出显⽰： 
  hm/(R*dxi) / G(end) = 16 
即表⾯传质项是扩散项的 16 倍，表⾯被瞬间拉向环境值。 
第五步：重新推导表⾯边界条件的离散形式 
归⼀化坐标 ξ = r/R(t) 下，表⾯控制体⽅程： 
  w_N (C_N^{n+1} - C_N^n) / dt 
    = (1/R^2) * [ D * dC/dxi |_{xi=1} - xi_w * D_f * (C_N - C_{N-1})/dxi ] 
表⾯边界条件： 
  (D/R) * dC/dxi |_{xi=1} = hm * (C_N - C_inf) 
即： 
  D * dC/dxi |_{xi=1} = -R * hm * (C_N - C_inf) 
代⼊控制体⽅程，展开后： 
  对⾓项 = w_N/dt + G_w + hm/R 
  右端项 = w_N/dt * C_N^old + hm/R * C_inf 
其中 G_w = xi_w * D_f / (R^2 * dxi)。 
关键：边界项是 hm/R，不是 hm/(R*dxi)，也不是 hm。 
第六步：修正表⾯边界项 
将表⾯边界项从 hm/(R*dxi) 改为 hm/R，温度边界同理从 h/(R*dxi) 改为 h/R。 
结果：C(end) 缓慢下降，t_dry = 73.03 h，物理上合理。 
5.4 最终结果 
  t_dry     = 73.03 h 
  终态半径  = 1.198 cm 
  终态Cmax  = 0.1500 
  终态T(1)  = 50.00 ℃ 
中⼼/表⾯含⽔率曲线符合物理规律： 
  - 表⾯（xi=1）在约 20 ⼩时内降到接近环境值 0.05 
  - 中⼼（xi=0）在前 10 ⼩时基本不变，之后缓慢下降 
  - 73 ⼩时时全场最⼤含⽔率降⾄ 0.15 
5.5 关键修正总结 
  | 修正项 | 错误写法 | 正确写法 | 原因 | 
  |---|---|---|---| 
  | 下对⾓ dl | [-G; 0] | [0; -G] | 索引偏移 | 
  | 上对⾓ du | [0; G] | [-G; 0] | 符号错误 | 
  | 表⾯边界(⽔分) | hm/(R*dxi) | hm/R | 多除了 dxi | 
  | 表⾯边界(温度) | h/(R*dxi) | h/R | 多除了 dxi | 
5.6 数值验证 
  Thomas 求解器与 MATLAB 内置求解器对⽐： 
    max|thomas - builtin| = 1.77e-15（机器精度） 
  内部界⾯通量： 
    G = xi_f * D_f / (R^2 * dxi)，不含 1/R 
  表⾯边界项量级检查： 
    hm/R = 4.0e-5 
    G_w  = 4.63e-5 
    ratio = 0.86（表⾯传质与扩散量级相当） 
5.7 结论 
问题4 代码经过六步调试，最终结果物理合理。核⼼修正为矩阵组装⽅向、 
上对⾓符号、以及表⾯边界条件的离散形式。最终 t_dry = 73.03 h， 
与题⽬背景的 2-3 天基本⼀致。

9.4 第 4 项：坐标变换⼀致性检验 
9.4.1 检验⽬的 
问题4 采⽤材料坐标（xi = r/R(t)）求解。理论上，同⼀个物理过程 
也可以⽤固定坐标（r）+ 坐标项的⽅式求解。两种写法应该等价。 
本项检验通过理论推导验证两种写法的等价性。 
9.4.2 两种写法的⽅程 
写法 A（材料坐标，问题4 代码采⽤）： 
  d(C_tilde)/dt = 1 / (R(t)^2 * xi) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
  其中 xi = r/R(t)，C_tilde(xi, t) = C(xi*R(t), t)。 
写法 B（固定坐标 + 坐标项）： 
  d(C)/dt |_r = 1/r * d/dr ( r * D * d(C)/dr ) + (R'(t)/R(t)) * r * d(C)/dr 
  其中 R'(t) = dR/dt。 
9.4.3 等价性推导 
由链式法则： 
  d(C)/dt |_r = d(C_tilde)/dt |_xi - (R'(t)/R(t)) * xi * d(C_tilde)/dxi 
同时，固定坐标下的空间导数： 
  d(C)/dr = (1/R(t)) * d(C_tilde)/dxi 
  r * d(C)/dr = xi * R(t) * (1/R(t)) * d(C_tilde)/dxi = xi * d(C_tilde)/dxi 
  d/dr ( r * D * d(C)/dr ) = (1/R(t)) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
代⼊写法 B： 
  d(C_tilde)/dt |_xi - (R'(t)/R(t)) * xi * d(C_tilde)/dxi 
    = 1/(xi*R(t)^2) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
      + (R'(t)/R(t)) * xi * d(C_tilde)/dxi 
移项，两边的坐标项相消： 
  d(C_tilde)/dt |_xi = 1/(R(t)^2 * xi) * d/dxi ( xi * D * d(C_tilde)/dxi ) 
即写法 A。 
9.4.4 结论 
两种写法在数学上严格等价： 
  - 写法 A 中，坐标项被"材料随⽹格均匀收缩"⾃动消去 
  - 写法 B 中，坐标项以对流项形式显式出现 
两种写法应给出相同的数值结果。如果不⼀致，说明推导或离散有误， 
⽽不是"模型不同"。 
问题4 代码采⽤写法 A，因为它与均匀仿射收缩假设⾃洽， 
且避免了显式的 R'(t) 对流项（该对流项会放⼤数值噪声）。 
9.4.5 检验说明 
由于资源限制，本项检验通过理论推导完成，未额外编写固定坐标 
版本代码。代码实现的⼀致性由第 6 项（固定半径⼀致性检验） 
间接验证：在 R(t) ≡ R0 的极限下，写法 A 精确退化为固定域模型。
