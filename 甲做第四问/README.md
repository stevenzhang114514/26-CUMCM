## 四、🔴 结果隔离纪律

用户明确要求「result 单独放一个文件夹以防污染」。本文件夹的落实方式：

| 目录 | 内容 | 可否进正式交付 |
|---|---|---|
| `results/` | `result4.xlsx`、`result4_运行信息.xlsx` | ✅ **是** |
| `results/对照/` | 与乙实现的对照版、B 版（固定半径）、端面版、结壳版、网格收敛版 | ❌ **否** |

**规则**：
1. `results/` 下**只有** result4 两个文件；任何对照版本一律进 `results/对照/`。
2. 对照文件一律带后缀 `_对照_<说明>.xlsx`，文件名即说明。
3. **M0（基线）与 M1（扩展）永不混在同一个文件里**。
